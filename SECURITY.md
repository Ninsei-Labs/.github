# Security

A vulnerability in Ninsei can put users' funds at risk, so it is reported privately and fixed before it is
made public.

## How to report

Use GitHub's private reporting: open the repository, then **Security**, then **Report a vulnerability**.
Only the maintainers see the report. Do not open a public issue, pull request or discussion about it.

For something that has no public repository, such as a deployed contract or the website, report it through
[Ninsei-Labs/sdk](https://github.com/Ninsei-Labs/sdk/security/advisories/new).

Please include:

- what is affected: the repository, the package version or the contract address, and the network;
- how to reproduce it, or a proof of concept;
- what an attacker could do with it.

## What happens next

We confirm that the report has arrived, keep you informed while we work on it, and agree a date with you
before anything is made public. Please do not disclose it before then. With your permission, the advisory
credits you.
